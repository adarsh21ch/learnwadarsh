# Learn with Adarsh — content brain

Everything behind the Instagram page lives here: who I am on camera, how I sound,
what I've researched, what I've scripted, and what actually performed.

**This repo is private and stays private.** It holds media-company briefs that may be
under NDA, unpublished scripts, and commercial terms.

> Nothing in here is connected to client project work. This is the personal brand only.

## How a reel gets made

```
 deal brief (PDF)
      │
      ▼
 topics/<slug>/BRIEF.md      what the agency actually asked for
      │
      ▼
 topics/<slug>/RESEARCH.md   ← I get educated FIRST. Independent sources.
 topics/<slug>/FACTCHECK.md  ← every agency claim verified ✅/⚠️/❌
      │
      ▼
 scripts/<yyyy-mm>-<slug>/   angles → hooks → script → CTA
      │
      ▼
 published/log.md            views, shares, saves — feeds back into hooks
```

**Rule: no script gets written before RESEARCH.md exists.** The bar for RESEARCH.md is
that I can talk about the topic unscripted for 10 minutes. If I can't, it isn't done.

## Folders

| Folder | What's in it |
|---|---|
| `PERSONA.md` | Who I am on camera — niche, audience, promise |
| `VOICE.md` | How I sound. Loaded before every script is written. |
| `brand/` | Content pillars, audience notes |
| `deals/` | One folder per media company: terms, deliverables, non-negotiables |
| `topics/` | Research per topic. The education layer. |
| `scripts/` | Reel scripts, one folder per reel |
| `carousels/` | Carousel posts |
| `published/` | What went live + performance numbers |
| `swipe-file/` | Hooks and formats that worked, mine and stolen |
