# Deals

One folder per media company. Each gets:

```
deals/<company>/
  terms.md        deliverables, cadence, deadlines, approver, payment
  non-negotiables.md   claims/numbers they REQUIRE on camera
  briefs/         the raw PDFs and videos they send
```

## Standing rules for every deal
1. **Disclose.** Paid partnership label on every sponsored post. Non-negotiable.
2. **Their numbers, my face.** Every required claim goes through FACTCHECK.md first,
   against a primary source (`SOURCING.md`). The brief itself is Tier 3 — it is the thing
   being checked, never the evidence. If a claim doesn't hold up it gets reframed or
   dropped, before recording, not after. Pushing back is cheaper than a debunk video.
3. **One narrative, serialized.** A brief with 20 points becomes 4 reels of 1 point each,
   never 1 reel of 20. Better retention, more content, same narrative covered.
